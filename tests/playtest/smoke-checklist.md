| C6 | 音效开/关切换即时生效；翻转音不刺耳、不刺耳到想静音 | `[主理人n=1]` ⚠️ `useBoardSound` 在测试中全被 mock |
| **C7** | **断线刷新后走子记录完整**：显示的「N 手」与实际落子数一致，且刷新前的每一手都能**点击回顾** | `[E2E·reconnect]` ⚠️ **修复前此用例失败**（`reconnect-BUG-01`），本条即其回归防线 |

> **C7 回归防线说明**：本条对应真实缺陷 `reconnect-BUG-01`——刷新后走子记录退化为「1 手」，第 1 手永久丢失。
> 根因：`GameState`（`gameLogic.ts:27-41`）只存 `moveCount` + `lastMove`，**从不持久化每手坐标**；
> `MoveHistory.tsx:26` 的 `entries` 是纯 `useState`，靠增量差分追加，刷新后归零。
> 修复前该用例以 `test.fail()` 标注（缺陷复现）；**方案 A 落地后必须移除 `test.fail()` 标注，否则
> 用例会以 "unexpectedly passed" 报错**。详见 `phase6-verdict.md` 与 `bug-report-template.md` 的「回归防线」。

## 别忘了自动化基线

```
npm run typecheck     # tsc --noEmit，含 e2e
npm test              # Vitest 单元/组件
npm run test:e2e      # Playwright 双窗口冒烟（需先装浏览器）
```

上面三项全绿 **不代表** 这次改动 OK —— B/C/D/E 四组是自动化盲区，**必须人眼过一遍**。
需要更全面的真人验证时，走 `playtest-protocol.md` 约人试玩。
